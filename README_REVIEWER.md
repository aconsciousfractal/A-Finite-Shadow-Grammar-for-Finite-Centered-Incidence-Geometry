# Reviewer Guide

This package is intended to make the paper snapshot inspectable with minimal setup.

## Inspect first

```text

paper/sections/02_finite_shadow_grammar.tex
```

## Main public claims

The paper promotes a bounded grammar/interface claim, not a new classification theorem:

- finite FCIG rows are admitted through the five-slot tuple `(n, X, I, rho, Phi)`;
- the standard-block balance dictionary is used as an organizing lens across Type-A and signed Type-B/C rows;
- the worked fingerprint examples show information beyond coarse cycle-type histograms;
- the fingerprint package remains descriptive and is not used as a tiling oracle or classifier.

## Boundary

The package does not claim a complete FCIG theory, a general Weyl-group theorem, a theorem for the separate signed-reversal route, a theorem-level `5568` bridge, or a full mechanism theorem for the M19/X05 rank-locus exhibit.
