# Source-Lock Crosswalk

This crosswalk identifies where the fields from `SOURCE_LOCK_SCHEMA.md` are published. The package uses a distributed record: values need not be duplicated in one large object.

## Field locations

| Field group | Authoritative public location |
|---|---|
| family identifier, admission, pointer status, owner, role | `artifacts/source_instance_manifest.json` |
| concrete carrier, action, finite row, and incidence rule | relevant manuscript section and declared artifact |
| representation or centered-operator channel | paper Sections 3-16, as applicable |
| fingerprint values | relevant manuscript table and replay artifact |
| classical or companion source | `paper/refs.bib` |
| immutable source version | bibliography entry, registry verification field, or package checksum |
| executable verification | `artifacts/public_evidence_routes.json` and declared script |
| proof-only or static verification | manuscript proof or manifest-pinned certificate and read-only checker |
| import and nonimport boundaries | manuscript wording, `CLAIM_BOUNDARY.md`, and `CLAIM_LEDGER.md` |

## Conditional-field locations

| Field | Main public locus when triggered |
|---|---|
| source partition | `G2` section and route X19 artifact |
| source layer | projective `F4` section and route X20 artifact |
| coefficient ring, characteristic, lattice basis | modular channel section, relevant row, and artifact |
| centering or quotient | centered-rank, modular, and source-coupling sections |
| coupling class | source-coupling subsection in Section 16 |
| placement embedding | selected `E7` and `E8` sections and artifacts |
| decision certificate | only an explicitly imported decision theorem; none is currently triggered |
