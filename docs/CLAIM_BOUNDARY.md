# Public Claim Boundary

This repository is a bounded public paper package for **A Finite-Shadow Grammar for Finite Centered Incidence Geometry**.

## Promoted Public Claims

1. The paper defines a five-slot finite-shadow grammar `S = (n, X, I, rho, Phi)` for current FCIG source rows.
2. The standard-block balance dictionary is used as an elementary representation-theoretic interface: position-value balance corresponds to vanishing of the standard Specht block in the relevant permutation channel.
3. The Type-A and signed Type-B/C examples show that the fingerprint package can detect finite structure not determined by coarse cycle-type histograms.
4. The M19/X05 exhibit is used only as a bounded example where the fingerprint package recovers a recurring hidden group from centered-operator rank-locus data.

## Explicit Non-Claims

This package does not claim:

- a complete theory of all finite centered incidence geometry;
- that `Phi` is a complete invariant;
- that rank mass, Specht rank, or Smith data decide tiling;
- a general Type-D, affine, or Weyl-group theorem;
- a theorem-level bridge from the number `5568`;
- a public theorem for the separate signed-reversal route;
- a full mechanism theorem for the M19/X05 rank-locus population or the `lat565` exception.

## Source Discipline

Public companion papers are cited as scholarly sources.  Companion artifact rows are used only as bounded source rows for the interface and are not treated as public mathematical authority unless separately released.
