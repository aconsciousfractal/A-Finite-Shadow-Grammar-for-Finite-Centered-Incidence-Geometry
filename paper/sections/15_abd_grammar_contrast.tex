\section{A/B, Dihedral, and Source-Layer Grammar Contrast}

The A/B/D and reflection-shadow material enters this paper as grammar contrast.  Its purpose is to show how the same admission discipline reacts when the source changes.  The signed-shadow routing table and signed-balance notes are the source locks for the Type-B/C contrast.  The dihedral vertex-shadow row adds a rank-two uncolored reflection-shadow contrast.  The length-colored \(G_2\) row adds a source-channel contrast: the finite set is still concrete, but the short/long partition is part of the data.  The projective \(F_4\) row adds a source-layer contrast on one finite set: the geometric projective Weyl row and the source matroid automorphism row have different centered behavior.  The projective \(H_3\) row adds a non-crystallographic source-channel contrast: flat-size incidence and Gram-angle geometry give different automorphism rows on the same 15 projective root pairs.  The projective \(H_4\) row adds the selected 60-pair analogue: flat-size and Gram-square channels have different full color automorphism groups on the same projective 600-cell root shadow.  The projective \(D_5\) row adds a control in the opposite direction: pair-level data over-automorphizes the 20-point projective root shadow, while \(A_2\) 3-flat incidence recovers the source action exactly.  The projective \(E_6\) row adds a second simply laced control: pair, flat, and circuit channels collapse to the classical source action, but the source summands \(U_{20}\) and \(U_{15}\) still separate parabolic row information hidden by total standard rank.  The projective \(E_7\) row adds the next control: pair and flat channels are already source-exact on \(\Pi_{63}\), but embedded \(A_5\) parabolic rows of the same abstract type and order have different \(U_{27}/U_{35}\) fingerprints.  The projective \(E_8\) row closes the local E-series comparison: pair and flat channels are already source-exact on \(\Pi_{120}\), standard parabolic placements of the same type fuse, and non-parabolic subsystem rows still separate source placement.

The contrast is deliberately asymmetric.  The Type-A row has a published theorem source, the Type-B/C row has a closed bounded artifact plus the self-contained elementary proof of the signed mirror-union row in \cref{prop:signed-mirror-union-balance}, the dihedral row has elementary cyclic/reflection algebra in \cref{prop:dihedral-standard-rows}, the \(G_2\) row has the source-channel facts in \cref{prop:g2-source-channel}, the projective \(F_4\) row has the source-layer facts in \cref{prop:f4-source-layer}, the projective \(H_3\) row has the flat-size/Gram-channel facts in \cref{prop:h3-source-channel}, the projective \(H_4\) row has the flat-size/Gram-square channel facts in \cref{prop:h4-source-channel}, the projective \(D_5\) row has the pair-channel/\(A_2\)-incidence control facts in \cref{prop:d5-root-shadow-control}, the projective \(E_6\) row has the channel-collapse/source-split facts in \cref{prop:e6-root-shadow-control}, the projective \(E_7\) row has the source-exact/embedded-parabolic facts in \cref{prop:e7-root-shadow-control}, and the projective \(E_8\) row has the source-exact/fusion/subsystem-separator facts in \cref{prop:e8-root-shadow-subsystem-separator}.  The D-side signed-reversal material belongs to its dedicated public companion theorem route\cite{BabanskyySignedReversal2026}.  This paper uses it only as a pointer and does not import theorem statements or proofs from it.

In this sense the grammar has teeth: it can admit bounded finite shadows while refusing to smuggle in neighboring theorem routes whose source locks are not yet closed.  It also shows real changes of behavior.  The Type-A row balances through one centered channel and is parity-fragile on the odd side; the signed row must balance two channels at once, but the mirror-union does so for every \(n\geq3\); the dihedral row is elementary, but it exposes rational-rank versus lattice-qualified Smith data; the \(G_2\) row shows that source partitions can be mathematically active rather than decorative; the projective \(F_4\) row shows that the admitted source layer can change the centered-rank interpretation on the same finite set; the projective \(H_3\) row shows that the ordinary standard block can be blind even when two source channels define different finite rows; the projective \(H_4\) row shows that the same carrier of 60 projective points can have a 14400-element flat-size source symmetry but only a 7200-element Gram-square geometric symmetry; the projective \(D_5\) row shows that pair-level data may be too coarse even in a simply laced shadow, while \(A_2\) incidence restores the source row; the projective \(E_6\) row shows that channel collapse to the classical source action does not make source-aware summand data redundant; the projective \(E_7\) row shows that source-exact pair channels still do not determine embedded parabolic row fingerprints; and the projective \(E_8\) row shows that when standard parabolic placements fuse, source-aware subsystem rows can still carry a finite-shadow separator.
